一条规则描述「哪个目录」和「哪个目录」之间怎么同步。双向规则会以修改时间较新的一侧为准。

按间隔执行：每隔 N 分钟同步一轮（默认 10 分钟）。每天 / 每周：到点跑一轮，其余时间不动。开机后执行：每次开机后先等「开机后延迟」（默认 30 分钟）再跑一轮，套件重启不会重复触发。失败会在 60 分钟后自动重试（开机后执行也照样重试），成功后回到正常排期，不会卡死在一次失败上。

同步设置

同步删除文件或覆盖冲突时，旧文件会移入各同步目录下的 .filesync-trash，超过保留天数自动清理，设为 0 表示永久保留。选「直接覆盖」则不会产生副本。若不想看到该目录，可在同步组的删除处理里选「不跟随」，再点「清理回收站」。

重要：网站目录请把 config.inc.php、.htaccess 等各站不同的配置文件加入「排除规则」，否则可能被另一站的旧版本覆盖，导致网站报错。

工作原理：两站规则拿两端清单和上次同步基线做三向比较，只传新增或修改的文件，冲突以修改时间较新者为准；多站互备每轮扫描全部成员，逐个文件挑出最新版本先拉回本机、再推给其余成员，删除需要多数成员同意（三站里两个站删了才真的删）。
压缩备份（可选）在同步成功后把本机目录打成 目录名-日期-时间.zip 放进另一个目录，按保留份数轮转；它是独立的时间点快照，不受同步覆盖影响。
源码备份是独立任务：自己按「每天 / 每周 / 间隔 / 开机后」定时，源目录可以是本机，也可以是路由器或 VPS 上的网站目录（远程用 SSH 把 tar 流直接写回本机，不在对方留临时文件），包名用任务名，只清理自己产生的包，保留份数填 0 表示不限。
同一个目录不要同时出现在两站规则和同步组里，两套基线会互相打架。
套件以 DSM 服务账号运行，需要读取共享文件夹的权限，因此安装时会被加入 administrators 组。SSH 私钥仅保存在本机 /var/packages/FileSync/var/keys，权限 0600。

添加站点

定时同步必须免密，所以要用密钥登录。远端站点需要先授权本套件的公钥：打开「密钥管理」点「复制安装命令」，到对方机器的终端粘贴执行一次即可，OpenWrt 与 Linux 通用。

① 复制安装命令在「密钥管理」里点「复制安装命令」，一条命令同时覆盖 dropbear 和 ~/.ssh。
② 到对方机器执行粘贴到终端，看到 OK 就装好了。重复执行不会写重复行，也不影响原来的密码登录。
③ 测试连接回到这里点「测试连接」，成功会显示对方系统与 rsync 版本。
密钥管理

密钥只在本机生成，私钥不会离开群晖。点「复制安装命令」，到对方机器的终端粘贴执行一次，看到 OK 就装好了——这条命令对 OpenWrt 和 Linux 都适用，重复执行也不会写重复。
